# chess-engine
---

This is a repository I am working on to learn rust, chess algorithms, gui and game development

It uses a custom made set of bitboard functions to represent and work with the board.
Using this I have created a basic rules engine that allows you to play a game of chess from start to finish, currrently it does not show win/loss/draw, the game simply reaches a halt as no more moves are possible.

To create the user interface and handle user input I used piston, this is currently very rudimentary.

Currently there is no bot implemented to play against but I am planning to add one and have been working towards it.
